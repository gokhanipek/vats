# Vats

A roguelike memory-duel deck builder. Colonists sleep in vats with their minds joined in a network. You duel them with fragments of their code, grow your deck, and try to reach Lucidity 6 and wake up before day 30.

This is a playable MVP to test whether the design is fun. See [docs/mvp.md](docs/mvp.md) for what's in it and [docs/GAME-DESIGN.md](docs/GAME-DESIGN.md) for the full design.

## Run it

```bash
npm install
npm run dev
```

`npm test` runs the test suite and `npm run build` builds into `dist/`.
